- Present only verified skills, project status and deployment claims.

- Document setup, architecture, testing and known limitations.
- Separate experiments from maintained portfolio projects.

- Presentar únicamente competencias, estados y despliegues verificados.

- Documentar instalación, arquitectura, pruebas y limitaciones conocidas.
- Separar los experimentos de los proyectos que se mantienen como portfolio.
