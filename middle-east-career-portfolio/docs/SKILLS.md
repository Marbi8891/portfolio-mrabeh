# SKILLS — Evidence-based skills model

> No percentages, no star ratings, no progress bars. A skill appears only with the **kind of
> evidence** behind it. Levels use four words: `Working knowledge`, `Basic`, `Learning`,
> `Professional use` — and `Professional use` requires a CONFIRMED experience entry.

## Evidence types

| Code | Evidence |
|---|---|
| `WORK` | Used in a job (FACT_CHECK experience row) |
| `PROJ` | Used in a public project (PROJECTS.md) |
| `EDU` | Covered in formal training (FACT_CHECK education row) |
| `SELF` | Self-study, no public artefact yet |
